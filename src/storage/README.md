# Storage

FSCom utiliza exclusivamente o SD com SPI compartilhado e sem autoformat. M3 inclui snapshots A/B de configuração com CRC, log segmentado/paginado, rascunhos/preferências redundantes e worker de persistência. Formato e limites em [M3_STATUS.md](../../docs/M3_STATUS.md); teste do candidato em [M3_USAGE.md](../../docs/M3_USAGE.md).
